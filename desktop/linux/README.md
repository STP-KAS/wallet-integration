# Linux

Same inject as Windows: **Kasware** and **Kastle** in a Chromium-based browser.

Firefox does not host these extensions. On Firefox, pay with a `kaspa:` URI or open [Kaspa NG](https://kaspa-ng.org).

## Install

1. Google Chrome, Chromium, Brave, or Microsoft Edge
2. Kasware and/or Kastle from the Chrome Web Store
3. Unlock, stay on this origin

## Run the demo

```bash
cd /path/to/wallet-integration
chmod +x desktop/linux/start.sh
./desktop/linux/start.sh
```

Open http://127.0.0.1:8765/desktop/linux/demo/

## Other Linux wallets (no inject)

Kaspa NG, KDX, Zelcore, Guarda, Ledger via KasVault.
